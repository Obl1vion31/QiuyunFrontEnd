# `scripts/` 受控维护脚本

本目录只保存需要人工确认后执行的项目维护脚本，不作为网页或 API 运行时入口。

一次性数据导入脚本只在已确认数据来源、字段映射、分类、去重方式、回滚边界和目标数据库后临时创建。脚本必须默认只读预检，写入必须使用显式参数并放在单个事务中；发现目标范围存在非本批次数据时应拒绝覆盖。执行完成并验证数据库结果后移除脚本，具体批次信息由执行输出和 Git 历史留痕。

任何维护脚本都不得包含连接串、共享密码、生产凭据或编造的业务数据。连接数据库前必须确认 `.env` 指向本次授权的目标分支。

`create-account.ts` 为已确认目标库创建内部账号，TTY 密码不显示，重复创建不修改原密码或角色。`migrate.ts` 使用共用连接入口执行已版本化迁移；`backup-database.ts` 只读导出精确保留数值的行 JSON，保存到被忽略的 `.tools/backups/`。当前公网与本地共享已确认分支，维护操作会影响公网，应先核对目标并备份；虚构测试使用独立数据库。

`restore-database.ts` 用于独立空库的恢复预检与演练。提供与源库不同的 `RESTORE_DATABASE_URL`，从 `.tools/backups/` 读取备份；默认只检查，显式 `--apply` 才事务写入。目标须预先建立匹配结构，任何表非空即拒绝，不覆盖生产数据。命令和恢复边界见数据库指南。
