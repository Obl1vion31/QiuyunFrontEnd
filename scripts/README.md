# `scripts/` 受控维护脚本

本目录只保存需要人工确认后执行的项目维护脚本，不作为网页或 API 运行时入口。

- `import-operations-content.mjs`：读取本地固定运营 Excel，校验 4–6 月 53 条记录、53 个项目文档超链接及推广/完成状态数量，并排除表内残留的 1 条 7 月记录；每条历史内容建立独立帖子和 V0，再创建关联排期。只有 Excel 明确标记为“推广帖”的记录才能进入推广状态；“推广已结束”映射为推广周期已结束，“推广已下架”默认映射为测试淘汰，讲义帖的已下架记录例外映射为推广周期已结束。完成情况按应发/实发时间计算。默认只读预检，只有传入 `--apply` 才连接 `.env` 指向的数据库，并在同一事务中清理数据库的 7 月排期后导入 4–6 月数据。

源文件放在 `public/excel/20260725 运营内容导入.xlsx`，其中 `.xlsx` 被 Git 忽略，不上传到公开仓库。执行写入前必须确认 `DATABASE_URL` 指向隔离的 Neon 开发分支并已完成最新迁移。导入使用“来源文件标识 + Excel 行号”作为幂等键，重复执行不会重复创建记录。不要在脚本中写入连接串、共享密码或新增模拟业务数据。
