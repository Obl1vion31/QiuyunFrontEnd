## 视觉与行为验收

| 项目 | 已验证标准 |
| --- | --- |
| 标题 | 名称、版本及 SVG 资料图标紧邻；图形16px、点击区域24px；推广和非推广共用，长标题自然换行 |
| 卡片密度 | 三列／1024px两列；自然标题高度，12px内容间距，同行等高，仅底部明细对齐；历史同类不保留大块灰底 |
| 填写 | 观察／行动64px初始高度；下一步选择和确认并排；定稿完整显示长文字且无编辑输入框 |
| 非零区间 | 首尾依据消耗、平台／实际开口、平台／实际留资任一非零事实；中间零值保留，尾零不延长，暂停后的转化仍计入；全零有明确空态 |
| 点击率 | 刷新区间变化保留人工值并取消确认；跨保存仍待核对，前后端阻止定稿；重新确认绑定新区间 |
| 明细 | 日期升序，同一行显示当日状态及指标；18日仍测试中、19日起待定，不能被次日安排覆盖；旧快照缺状态显示未记录 |
| 气泡 | 原位开关，卡片坐标及页面滚动不变；悬停、点击保持、Esc和外部点击沿用共享控制器 |
| 非推广 | 已填／待填统一按真实发布时间升序，同帖首轮在二轮前，完成录入不跳位置，缺日期的旧记录在末尾 |
| 会议名称 | 自动标题随成功读取的有效区间预览，并与区间原事务保存；兼容旧标准标题未同步，自定义保留，刷新失败不改名 |
| 事项 | 问题／方案同为64px，40px进度及复选框首行对齐；新增行×可删首／中／末行，不影响其他输入和焦点；已有编号不可×删除 |
| 草稿／定稿 | 半填写事项保存回显，定稿定位缺少的问题；会前不执行安排，明确未生效；会后使用冻结生效日，解决事项不再流入下场 |
