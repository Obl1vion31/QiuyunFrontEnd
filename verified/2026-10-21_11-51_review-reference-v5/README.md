# 复盘视觉参考 · 状态气泡与列间距

状态：已自检，待用户确认。独立示例参考，不连接业务 API 或数据库；本轮只替换第四版的状态编辑条并调整相关列间距。

状态列为 112px，状态名称与修改入口两行、表头均居中；长状态文字与消耗输入框间隔实测约 23px，五项数字输入仍至少 88px。1440px 参考视口可完整展示一行，窄屏局部横向查看。

点击修改，在状态旁显示无背景遮罩的锚定气泡；无日期选择，也不增加数据行。气泡包含原状态、修改为、更新原因、原→新预览和未保存／已保存标识。保存前表格显示原状态；保存后气泡保留只读回执，可关闭、重新查看或再次修改。原状态快照在本次变更中保持固定。

## 实际检查

覆盖 1920、1440、1280、1024、736、390、320px；实际查看桌面与手机关键截图。气泡避让边缘、箭头指向状态入口，无页面横向溢出或脚本错误；打开、修改及保存全过程，数据行高度保持 72px，其他记录位置不变。

取消保留原状态和指标；关闭／Esc 保留未保存草稿并返回入口，第二行明确标识未保存，重新打开可继续。保存保留指标、成本、仍合法的次日安排与原输入节点；原次日选择失效时明确提示重新确认。已保存记录可再次打开查看原状态、新状态及原因，减少动态效果已检查。详见[检查记录](check.json)。
