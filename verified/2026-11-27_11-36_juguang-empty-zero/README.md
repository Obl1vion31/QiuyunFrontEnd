# 聚光暂无报表默认零值与保存

应用代码：`f13933de52559ecea8236b585a290b80e44489e6`；状态：已自检并发布，待用户反馈。

聚光成功查询但暂无当天报表时，未填写且未被手动改动的消耗、曝光量、点击量、平台开口、平台留资默认填 0，保留已有输入。实际人数和次日安排仍由人填写。曝光量和点击量同时为 0 时可直接保存，不再要求先取得聚光来源；非零流量继续沿用来源核对。没有来源的零值不生成官方来源，零曝光时点击率显示“—”。

断网、超时或授权失效仍提示读取问题，不把未知数据自动当成零；用户明确手填曝光量和点击量为 0 后可以保存。接口结构、权限与数据库结构保持。
