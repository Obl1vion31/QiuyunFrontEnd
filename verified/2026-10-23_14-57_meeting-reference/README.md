- 总览草稿返回、候选全选后确认生成五卡、比较层级、缺失点击率与真实零值、计算字体及无整页横向溢出。
- Inspector 高 820px，头尾固定、正文单独滚动；打开不改变背景卡片几何，未保存取消保留输入，逐卡保存与取消更正后焦点返回。
- 定稿缺项定位及补齐后的正向确认；非推广示意节点的门槛、录入和明确不复盘；草稿不锁定、V0 次日锁定、V1 草稿继续 V0、V1 定稿切换。
- 修改理由必填、更正及版本切换保留当天指标；事项表格列对齐、勾选解决保留输入、无历史状态及减少动态效果。

非推广当前仅示意一个节点，月例会仅展示总览共同外壳。全量真实候选、正式月度业务、搜索筛选与往期补充、网络失败、并发、真实持久化及历史流转仍须在正式接入时验收；本批通过不延伸为这些能力已完成。
