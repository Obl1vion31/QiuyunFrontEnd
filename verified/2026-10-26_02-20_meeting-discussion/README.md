## 通过标准与实际验证

| 范围 | 已检查结果 |
| --- | --- |
| 总览 | 日期／类型、会议／版本与操作同排；长标题省略且可查看全名；历史整体及单会议默认关闭 |
| 讨论 | 仅最新会前开放结论、推广观察／行动、下一步及事项；率、指标和非推广只读；原位改文字 |
| 保存与定稿 | 保存不新增V、不执行安排或事项；保存期间继续写保留输入；会后追加版本并于次日生效 |
| 冻结与并发 | 客户端不能注入指标；来源版本／更新时间校验；后续业务数据变化不替换会前材料；旧版本只读且快照不回写 |
| 均值 | 同期9份首轮含本帖／零值；跨期样本可比较，轮次／学科／截止日隔离；推广人工率跨版本去重；单样本不做差值结论 |
| PDF | 成功定稿自动生成，版本唯一；补充上传不覆盖；失败、中断、重复与并发重试不重复会议业务；登录、同源及下载核对 |
| 视觉 | 1920／1440／1280／1024桌面；长标题、长结论、无历史、缺资料、草稿、最新会前、会后、历史只读；公共UI含移动端回归 |
| 打印 | 中文可搜索／复制，A4正文完整，版本页码正确；常规4页及长文6页逐页渲染查看，未发现截断、乱码或额外空白页 |
