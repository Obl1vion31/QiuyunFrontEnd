## 验收范围

| 项目 | 实际检查 |
| --- | --- |
| 比较 | 指标旁只写带符号pp，每卡一处样本；旧快照只用原有冻结样本补展示，原JSON不改 |
| 编辑 | 默认只读，仅最新有效版本开放文字和期限内安排；另存V号，原稿保留，指标和数据区间不变 |
| 截止 | 上海生效日零点起安排与回溯锁定；文字仍可修订，生效日期不顺延 |
| 回溯 | 确认影响、取消、事务撤销事项、失效版本保留、V号续增；恢复后重新确认并会后定稿 |
| 业务保护 | 白名单、来源与更新时间CAS；文本修订不重复测试轮或覆盖日度更正；事项冲突禁止覆盖回溯 |
| PDF | 网页组件和MiSans复用；常规与真实V2均3页、长文5页逐页检查，中文文字可提取，末尾标记完整；旧模板成功替换、失败留旧、手工附件保留 |
| 桌面 | 1920／1440／1280／1024只读、编辑、卡片；共享UI含移动端回归 |

206项规则测试、完整例会七组浏览器回归、新模式／回溯／PDF专项、公共UI、类型检查、构建及db:check通过。正式运行包已实际冷启动 Chromium 并生成中文PDF。

真实会后V2已核对面试课第二轮③ `+0.99 pp`、第一时间解析引流版 `-0.53 pp / -8.65 pp`；原3份快照、推广日度事实、非推广指标及复盘和事项与私有备份逐项比对保留。生产验收仅重建指定版本的自动PDF，未代填结论或增加定稿版本。

发布源 `8f53a63`（主要实现 `ed932c5`），正式部署 `dpl_CwoW42dpYjogGjGXczA3voxfXfpW`。候选4项动态探针、95项公网检查与61个静态资源哈希通过；真实V2四档桌面只读／编辑、旧V0只读与过期提示、总览归档及三页正式PDF已查看。详见[发布核对](release.json)、[公网检查](public-smoke.json)、[数据保留检查](production-preservation.json)。
