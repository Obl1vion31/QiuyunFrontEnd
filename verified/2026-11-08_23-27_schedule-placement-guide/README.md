## 交付与操作

- 未发布排期拖到空日期保留发送时刻；有效且无需理由时直接保存。目标日已有内容时，在原单层面板选择加入或与某篇对换，预览双方完整时间。详情的“移动／对换”提供同一键盘流程。
- 过去时刻、跨原 Week、封存后调整及月份权限由服务端检查；对换双方在同一事务保存，重新核对保留选择与原因。重复请求不重复写入；写入成功但展示读取失败时只重试读取。
- 编辑以真实字段与初始值比较，系统拼合的日期时间不重复计入；只看、慢回填和改回原值不误报，真实输入继续受保护。
- 设置 → 使用说明 → 第二部分“月例会与排期”，包含五阶段流程、Week、遗留接纳、V0与当前执行区别，以及三张真实样例操作图。员工可阅读，维护入口仅管理员可见；图片懒加载预留尺寸。
- 8号新建周会默认至7号，首次为1—7号，之后接上一场截止日；调整8号以后未发布排期只改当前执行与历史。管理员确认预排期和封存门禁保持，冻结计划、会议和PDF不变。
