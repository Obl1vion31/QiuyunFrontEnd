# 复盘视觉参考 · 每日列比例与状态衔接

状态：已自检，待用户确认。独立示例参考，本轮只调整每日复盘的列比例与状态衔接，保留 MiSans、上方生命周期、单行录入和状态气泡。

## 本轮标准

- 修改当日状态只提供原状态允许衔接的后继。测试中：测试暂停、测试结果待定、测试转放量、测试淘汰；不含当前状态或继续测试。
- 测试暂停可以恢复测试、转待定、放量或淘汰；测试结果待定只可转放量或淘汰。放量使用自己的暂停、恢复与结束路径。
- 打开及再次修改均默认空选，必须选择状态并填写原因。次日安排仍可选择继续当前阶段，和当日修改分开。
- 淘汰或结束后保留当日真实跑量录入，次日安排显示“无需后续动作”。参考交互同步概览与数量；当日修改后选择继续放量并完成时，概览也正确显示放量。
- 日期、内容、状态、五项录入、实际成本、次日安排、提交保持稳定单行。日期居中，状态与修改两行居中；数字框按录入需要固定宽度，剩余空间分配给内容、成本、次日安排与列间距。
