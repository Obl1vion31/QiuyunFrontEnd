## 行为与入口

- 推广历史选中一天，在原 Inspector 的「更正笔记 ID」中选择「从该日起」或「本版本全部阶段」。保存前确认版本、原 ID、新 ID 和生效范围；保存后原位更新，失败保留输入。
- 后一次操作覆盖所选范围内的旧切换：10 月 31 日起改 C，则之后原来的 B 失效；此前日期和其他内容版本保持。业务历史保留所有更正。
- 推广改帖创建、排期时不填 ID。首次发布登记明确选择「继承上一版本」或「填写新 ID」，默认均不选。继承按本次上海实发日期解析，确认后复制；旧版之后更正不联动新版。
- 每日复盘仅保留缺失 ID 的首次补填；批量、补录、查帖及资料按版本、数据日期解析。普通非推广沿用原流程。
- 使用说明位于系统设置，员工和管理员均可查看。
