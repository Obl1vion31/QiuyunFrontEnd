## 视觉与交互验收标准

| 项目 | 通过标准与本轮结果 |
| --- | --- |
| 布局 | 1920／1440／1280px 三列铺满；1024px 两列以保证金额、标题与输入可读。不出现四列硬塞和页面横向溢出。 |
| 等高 | 可见推广与非推广卡片等高，内容多少不改变单张高度；自动测量误差小于1 CSS px。正常与长标题均检查。 |
| 连续性 | 沿用共享 Sidebar、Toolbar、MiSans、控件与颜色；与推广、非推广、排期页面的公共坐标检查通过。 |
| 数据层级 | 实际开口成本、实际留资成本、点击率放在同一组；消耗和人数作为摘要。0为有效值，缺值与零分母不补零。 |
| 比较 | 本帖历史在前；无样本折叠为一行。历史同类仅样本量和核心指标；不再展示同期比较、成本相差或模糊天数。 |
| 普通填写 | 点击率待补充输入、观察／行动两行文本、次日日期及状态均在卡片内完成；确认后可修改。明细仅底部展开。 |
| 候选 | 先勾选并确认纳入，再展示卡片；全选只含本期候选，历史阶段另选。 |
| 推广／非推广 | 推广指标去专属入口。非推广卡片确认立即保存正式数据；未确认内容可保存会议草稿；可填理由标记不复盘。 |
| 草稿 | 不要求填齐；保存后返回表格，重新进入保留输入和候选。已定稿后的未发布修改标为会后／修订草稿。 |
| 总览与历史 | 周／月共用表格，日期、复盘区间、年／月／周次、草稿与版本可辨。历史按会议折叠，展开可直接查看每个V0／V1版本。 |
| 会前 | V0冻结材料、初步结论及来源；不执行状态或事项结果。点击率、衡量情况、具体动作、核心结论及非推广节点须完成。 |
| 会后 | 通常V1，追加版本；另须下一步行动。定稿后才流转次日状态和事项，同日最新版优先，跨日历史保留。 |
| 日期衔接 | 23号开会看截至22号的数据，23号仍正常；决定从24号起生效。24号填写23号数据时，次日安排已继承。 |
| 锁定与更正 | 显示“（例会决定）”及来源版本，次日安排置灰；另填修改理由才能变更。保留指标输入，拒绝过期覆盖。已录日度的次日安排同步更正。 |
| 事项 | 问题／解决方案／进度／是否已解决纯表格；无历史显示“无”。未解决保留方案进入下场，只有会后定稿解决后退出。 |
| 错误与刷新 | 500ms内安静，慢读只有一处反馈。来源变更拦截定稿；失败、取消保留输入，旧版本不被覆盖。 |
