# 例会大快照读取优化

状态：已发布，正式域名与独立部署已核对为 READY。源码基线 `c245840`（应用 `3ebc25d`），候选源码 `841ee3edb5d1f445b0df92eeaf07c42542467cbd`。独立工作树 `.tools/releases/snapshot-transfer-20261105`，分支 `codex/meeting-read-projections`。

## 发现与修复

- 公共决定读取曾取回所有完整例会快照及整条更正审计；现在由 PostgreSQL 仅返回决定回放所需字段，仍包含失效版／草稿的撤销事件。
- 推广日度与周会材料重复读取推广上下文；现在显式复用本次请求的结果。没有跨请求缓存版本凭据。
- 周会历史比较、旧版候选计数、月度事项和查帖关联，原先在应用内筛选完整历史；现在先在数据库内投影或筛选。比较保留原事实、缺失键／null、数组顺序、来源指纹和最新有效会后事项；关联查询只匹配字符串 scheduleId。
- 例会总览只取摘要；进入单场时只读取该场草稿及当前显示版本的完整快照，其他版本保留导航／决定／回溯摘要；上一期行动仅取行动文字。
