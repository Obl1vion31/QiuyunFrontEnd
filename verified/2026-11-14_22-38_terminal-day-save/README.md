# 终态确认日复盘保存修复

状态：已发布、已自检，待用户反馈。运行源码 `c6383bb`，部署 `dpl_8G2B91ZE85RArAfwC6Y4wKKyxd6a` 已 READY 并指向正式域名。

## 原因与修复

前一天的次日安排已结束投放，第二天又有一条相同终态的明确当日状态记录。每日页面据当日记录开放指标，旧回放却只允许最后投放日的终态指标，导致合法的确认日被返回 HTTP 409「复盘选择与当前推广阶段不匹配」。

新版允许同日、同状态、同阶段的明确终态确认保存指标；原最后投放日、阶段区间及终态保持。没有当天匹配记录、其他日期、状态不符及恢复旧投放的行为仍拒绝。实现位于 `promotion-replay.mjs`，沿用单条／批量保存事务与历史规则。

- 只读核对用户所指帖子后，私有历史在本机回放复现；没有向正式库代填0。原始业务数据保持在私有工具目录。
