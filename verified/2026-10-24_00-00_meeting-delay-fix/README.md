## 验收标准与结果

| 项目 | 已检查的标准 |
| --- | --- |
| 页面层级 | 总览与当前会议互斥；会议名称只在顶部出现一次；编辑态仅底部一个保存草稿，保存成功返回表格 |
| 密度 | 常规三列、1024px 两列；同组同行等高，不跨行、跨类型强制统一；非推广没有额外固定高度 |
| 输入 | 观察／行动初始高度一致；中文、金额、状态和完整 ID 可读，控件沿用 MiSans 与共享规格 |
| 明细 | 编辑与冻结态共用；触发器不移动；开关卡片、字段和 scrollY 坐标一致；Esc、外点和上下边界通过 |
| 笔记 ID | 缺失直接输入，已有直接只读；保存、草稿重入及更正刷新通过；更正不改变材料指纹，新定稿不含 ID |
| 延期 | 当前应发＋2 小时开始，之后每24小时一条；旧修订不参与计算、必填、历史或提醒 |
| 删除 | 改期成功／审批通过才删除；失败、驳回、不改日期保留；旧修订提交被拒绝；实发更正删除失效原因 |
| 数据兼容 | 保留改期日期与理由、发布事实、推广指标；清理审批与推广结构化副本、multipart 请求；重复清理无变化 |
| 例会回归 | 内联确认、草稿返回、会前 V0／会后 V1、冻结来源、次日安排锁定与修改理由、事项流转通过 |

截图中的延期场景：原定20日18:00，改为22日18:00，23日18:00实发；改期前两条原因实际删除，最新排期只填写22日这一条，明确显示晚发布1天。相关资料手动收起，以展示完整的当前原因。
