# 验证

`pnpm test:pauses` 在构建后验收员工创建／调整／恢复团队暂停、同源与登录保护、重复提交、并发版本，以及桌面／390／320px 布局。`promotion-pauses.test.ts` 和迁移测试覆盖服务端时间边界、整日略过、原有等待保留、历史回放与旧应用兼容。

`pnpm test` 运行现有业务规则检查与 `auth.test.ts` 的独立内存 PostgreSQL 认证测试，覆盖哈希、初始化幂等、会话撤销、角色来源、CSRF 和多实例限流。

先执行 `pnpm build`，再执行 `pnpm test:browser` 和 `pnpm test:annual-plan`。浏览器验收使用 `auth.fixture.ts` 自带的 PGlite 数据库、虚构账号与独立端口，覆盖真实 HTTP 权限、业务写入和桌面／手机登录体验，不连接 `.env` 中的共享 Neon 数据库。

浏览器工具通过 `PLAYWRIGHT_MODULE` 指定；默认读取项目内被忽略的 `.tools/tooling/node_modules/playwright/index.mjs`。Chromium 可通过 `PLAYWRIGHT_BROWSERS_PATH` 指定下载位置。截图保存在 `.tools/test-artifacts/`，不放入公开资源。

公网验收只做已授权账号登录、读取和无权限请求，不向共享业务库添加虚构数据。构建前需使用 Node 22；本机工具目录、测试产物及数据库备份不会提交或发布。

历史迁移含特定导入批次断言，隔离测试从当前 schema 建立业务结构，再执行本次认证 SQL；不会修改已共享的历史迁移，也不会使用真实业务数据补足断言。Chromium 系统库与中文字体可在 `.tools/system/` 解压，并用 `LD_LIBRARY_PATH`、`FONTCONFIG_FILE` 提供，避免修改系统配置。

年度规划测试覆盖半月边界、付费子区间汇总、自由备注、旧快照恢复、乐观锁、管理员权限、年度复制和并发防覆盖。追加迁移从上一个完整结构快照在隔离 PostgreSQL 验证，浏览器同时检查桌面全年对齐、跨页初始化和手机编辑。

`pnpm test:workflows` 在构建后验收延期逐日理由、实发原子提交、改期权限与并发审批、临时分类、非推广筛选、跳过／恢复及同类基准，并检查桌面与手机交互。`schedule-workflow.test.ts` 验证纯规则和事务，迁移测试从上一结构快照验证历史补齐与快照保留。

`pnpm test:reviews` 在构建后使用隔离账号验收待定区间、次日计划、阶段快照版本、服务端例会引用、私有图片和桌面／390／320px 跨页布局。`promotion-intervals-snapshots.test.ts` 覆盖时间边界、手动恢复、历史影响确认、节假日交叠、任意时间段聚合、成本、缺失与快照不变；`review-intervals-migration.test.ts` 从上一结构验证追加迁移与旧会议保留。

## 界面一致性验收

先 `pnpm build`，再运行 `pnpm test:ui`；使用同一隔离库和虚构账号。测试覆盖 1440、390、320px，检查六个业务页的工具栏坐标／尺寸、标题起点和正文留白；公共误差不超过 1 CSS px。推广每日、阶段和历史连续切换时同时比较顶栏、按钮的 DOM 身份与坐标，不能只检查页面截图或高度。

Inspector 验收检查左侧列表节点持续存在、无文档请求、滚动和筛选保留，以及快速选择、未保存取消、Esc、焦点返回、浏览器前进后退、移动端与减少动态效果。非推广检查同名排期独立分组、首轮／二轮基准隔离、分组和单轮排序、保存刷新及网络失败保留输入。异步详情还需通过排期工作流和年度规划回归检查旧响应不会覆盖新选择。

非推广分组开关须核对同一六列表头、筛选与列坐标、真实行节点持续存在；分组每个排期版本只显示一次日期、帖子与分类，不分组每轮恢复完整信息。切换与浏览器前后退均无新文档请求，详情中的未保存输入保留；辅助指标计算字号不低于 12px。年度规划验收空年度、异步版本历史、版本内容的真实计算样式及北京时间格式，不能仅凭静态 CSS 判断字体一致。每次前端交付同时核对同类组件、反馈、无必要布局跳动、冗余文案及范围外修改。

展示方式使用独立单选分段控件，和条件筛选统一 36px 高度。发布浏览器同时检查编辑／发布抽屉的宽度、深蓝标题栏颜色、头部和底部坐标，以及字段成对对齐、40px 控件、选项分组与长内容滚动；已有未保存保护、权限、分享文案和历史空链接继续验收，日历卡片保持原设计。

完整日期时间验收覆盖新建／编辑／改帖、发布及管理员更正、员工改期申请、例会创建：检查同一原生日期／时间控件、左右对齐、40px 规格、原字段同步、完整必填、默认／只读／禁用、失败保留及实际保存后的上海时间，已有精确秒数不得因补链接而改变。日期区间继续只有日期。六页原生控件计算字体与统计／详情操作区字号、字重、主要动作可用性同时核对。

全局规则变更还需检查所有适用消费者：设置、例会创建／编辑、年度编辑、待定区间、阶段筛选和推广历史更正的真实控件规格、只读样式、窄屏溢出，以及长表单滚动后头尾稳定；不以只验证当前页面代替全局检查。

`pnpm test:publication` 在构建后验证统一未来时间登记、完整分享文案、历史空链接、旧预约接口停用、权限和并发，以及 1440／390／320px 默认月历、发布状态与推广身份、同日多帖、两行卡片和长标题单行省略、详情打开后的布局、筛选、点击日期新建、未保存保护和失败保留。`publication-workflow.test.ts` 用固定北京时间验证 17:00 登记 20:00、历史边界、到期理由推进及更正留痕；原迁移兼容测试继续保留。业务写入仅使用隔离库。

`pnpm test:registration` 验证 2 小时尚未登记、改期的实时审批边界、新旧统一 2 小时，以及 1440／390／320px 待办／资料／历史分层、逐日草稿保留、单一正文滚动与固定头尾、手机背景锁定和编辑表单转审批。`registration-deadline.test.ts` 使用固定时间验证临界点、按真实发布时间结算、逐日原因、追加迁移、历史状态修正及人工原因保留。

权限验收通过 `business-permissions.test.ts` 和 `pnpm test:interaction` 的真实设置入口检查：默认矩阵、逐账号直接／审核／关闭、复合修改整体审核、新建不提前落库、重复提交与审核、授权撤销、过期申请和删除阻断。日期核对 SSR 与异步回显一致；详情读取在 100／450ms 内无加载闪烁，慢请求只出现目标面板一处加载；来源卡片保持原样。关闭动画中原生 dialog 仍打开，结束后关闭；减少动态效果无额外等待。站内未保存保护操作真实应用确认框，取消保留输入、选择、滚动与焦点，浏览器刷新另验原生保护。

业务确认验收覆盖桌面／390／320px 删除排期：默认取消、Esc、焦点返回、重复点击、取消无写入、确认实际删除及已有改帖继续受保护；例会草稿删除、站内导航与退出取消保留输入，失败留在原位置可重试。年度历史读取／恢复和例会定稿通过 `test:annual-plan`、`test:reviews` 检查站内确认及局部错误。监听原生 dialog 作为失败，不自动接受业务确认。

`pnpm test:timeline` 在构建后使用隔离库验收首次业务日期、末日空下一步、次日计划、无 ID／指标的当日暂停、其他帖子草稿与公共节点保留、排期 Inspector 未保存保护、整篇不复盘及恢复、排期待审和分类配置回填；检查 1440／390／320px。规则与迁移测试补充历史开始日提前／延后、最早缺口、冲突预览与归档、请求幂等、指纹防覆盖以及旧解析帖事实保留。

首次安排与排期待审回归额外检查：每日首次行的桌面高度与条件字段、无活动明细旧终态不进入首次队列且接口拒绝重启、历史状态筛选、设置无重复入口、审批沿用台账行、详情正文／差异／日期的 `scrollWidth` 不超过 `clientWidth`。`pnpm test:interaction` 保留旧审核地址兼容访问与原权限断言；排期审批从实际排期入口验收。

`pnpm test:pending` 使用隔离库与真实行内操作验证待定／测试待定／放量暂停、含首尾的逐日记录、T+1 日期、截止缩短、提前恢复、同行编辑草稿保护、网络失败重试和正常日度推进；额外核对单日逾期区间直接显示截止日次日，保存不二次顺延，摘要不重复解释。1440／1280／390／320px 比较状态行与数据行边界、实际控件规格和字体，桌面日期／选项／保存同行，短状态不拆字，窄屏展开保留草稿且不溢出。规则测试补充连续覆盖、长区间压缩和不产生零指标。

日度卡片按输入、计算结果、完成操作三组验收，优先保护可读宽度与整体比例，空间不足允许完整换行。`pnpm test:cards` 在 1920／1600／1440／1366／1280／1080／900／768／600／390／320px 实际填写金额、人数及 ID，检查输入文本可完整阅读、五项等宽、成本标签及数值不裁切、下一步尺寸、有无 ID 的共同头部与指标起点；覆盖暂停草稿、零分母、失败重试与真实保存。截图和计算尺寸位于 `.tools/test-artifacts/review-cards-verified/`，须实际打开图像审查比例、层级和空间，不能只运行断言或要求九个元素同行。原区间、笔记 ID 必填与局部刷新由 `test:pending`、`test:timeline` 继续回归。

`pnpm test:motion` 使用隔离库在 1440／1280／390／320px 逐帧检查排期详情、发布登记、编辑排期、创建改帖的面板几何、遮罩透明度、背景日历、滚动位置与锁定时机；另验快速重开、嵌套确认和减少动态效果。退出期间不提前改变定位或隐藏，面板与遮罩归零后才关闭，覆盖式不改变背景宽度，停靠式轨道收拢的终帧误差不超过 1px。记录保存在 `.tools/test-artifacts/panel-motion-regression.json`，同类共享组件继续通过全部跨页浏览器回归验收。
