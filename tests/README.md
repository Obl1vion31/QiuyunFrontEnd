# 验证

`pnpm test:pauses` 在构建后验收员工创建／调整／恢复团队暂停、同源与登录保护、重复提交、并发版本，以及桌面／390／320px 布局。`promotion-pauses.test.ts` 和迁移测试覆盖服务端时间边界、整日略过、原有等待保留、历史回放与旧应用兼容。

`pnpm test` 运行现有业务规则检查与 `auth.test.ts` 的独立内存 PostgreSQL 认证测试，覆盖哈希、初始化幂等、会话撤销、角色来源、CSRF 和多实例限流。

先执行 `pnpm build`，再执行 `pnpm test:browser` 和 `pnpm test:annual-plan`。浏览器验收使用 `auth.fixture.ts` 自带的 PGlite 数据库、虚构账号与独立端口，覆盖真实 HTTP 权限、业务写入和桌面／手机登录体验，不连接 `.env` 中的共享 Neon 数据库。

浏览器工具通过 `PLAYWRIGHT_MODULE` 指定；默认读取项目内被忽略的 `.tools/tooling/node_modules/playwright/index.mjs`。Chromium 可通过 `PLAYWRIGHT_BROWSERS_PATH` 指定下载位置。截图保存在 `.tools/test-artifacts/`，不放入公开资源。

公网验收只做已授权账号登录、读取和无权限请求，不向共享业务库添加虚构数据。构建前需使用 Node 22；本机工具目录、测试产物及数据库备份不会提交或发布。

历史迁移含特定导入批次断言，隔离测试从当前 schema 建立业务结构，再执行本次认证 SQL；不会修改已共享的历史迁移，也不会使用真实业务数据补足断言。Chromium 系统库与中文字体可在 `.tools/system/` 解压，并用 `LD_LIBRARY_PATH`、`FONTCONFIG_FILE` 提供，避免修改系统配置。

年度规划测试覆盖半月边界、付费子区间汇总、自由备注、旧快照恢复、乐观锁、管理员权限、年度复制和并发防覆盖。追加迁移从上一个完整结构快照在隔离 PostgreSQL 验证，浏览器同时检查桌面全年对齐、跨页初始化和手机编辑。

`pnpm test:workflows` 在构建后验收延期逐日理由、实发原子提交、改期权限与并发审批、临时分类、非推广筛选、跳过／恢复及同类基准，并检查桌面与手机交互。`schedule-workflow.test.ts` 验证纯规则和事务，迁移测试从上一结构快照验证历史补齐与快照保留。

`pnpm test:reviews` 在构建后使用隔离账号验收待定区间、次日计划、阶段快照版本、服务端例会引用、私有图片和桌面／390／320px 跨页布局。`promotion-intervals-snapshots.test.ts` 覆盖时间边界、手动恢复、历史影响确认、节假日交叠、任意时间段聚合、成本、缺失与快照不变；`review-intervals-migration.test.ts` 从上一结构验证追加迁移与旧会议保留。

## 界面一致性验收

先 `pnpm build`，再运行 `pnpm test:ui`；使用同一隔离库和虚构账号。测试覆盖 1440、390、320px，检查六个业务页的工具栏坐标／尺寸、标题起点和正文留白；公共误差不超过 1 CSS px。推广每日、阶段和历史连续切换时同时比较顶栏、按钮的 DOM 身份与坐标，不能只检查页面截图或高度。

Inspector 验收检查左侧列表节点持续存在、无文档请求、滚动和筛选保留，以及快速选择、未保存取消、Esc、焦点返回、浏览器前进后退、移动端与减少动态效果。非推广检查同名排期独立分组、首轮／二轮基准隔离、分组和单轮排序、保存刷新及网络失败保留输入。异步详情还需通过排期工作流和年度规划回归检查旧响应不会覆盖新选择。

非推广分组开关须核对同一六列表头、筛选与列坐标、真实行节点持续存在，切换与浏览器前后退均无新文档请求，详情中的未保存输入保留；辅助指标计算字号不低于 12px。年度规划验收空年度、异步版本历史、版本内容的真实计算样式及北京时间格式，不能仅凭静态 CSS 判断字体一致。每次前端交付同时核对同类组件、反馈、无必要布局跳动、冗余文案及范围外修改。

展示方式使用独立单选分段控件，和条件筛选统一 36px 高度。发布浏览器同时检查编辑／发布抽屉的宽度、深蓝标题栏颜色、头部和底部坐标，以及字段成对对齐、40px 控件、选项分组与长内容滚动；已有未保存保护、权限、分享文案和历史空链接继续验收，日历卡片保持原设计。

全局规则变更还需检查所有适用消费者：设置、例会创建／编辑、年度编辑、待定区间、阶段筛选和推广历史更正的真实控件规格、只读样式、窄屏溢出，以及长表单滚动后头尾稳定；不以只验证当前页面代替全局检查。

pnpm build
pnpm test:ui

pnpm test:browser

`pnpm test:publication` 在构建后验证统一未来时间登记、完整分享文案、历史空链接、旧预约接口停用、权限和并发，以及 1440／390／320px 默认月历、发布状态与推广身份、同日多帖、两行卡片和长标题单行省略、详情打开后的布局、筛选、点击日期新建、未保存保护和失败保留。`publication-workflow.test.ts` 用固定北京时间验证 17:00 登记 20:00、历史边界、到期理由推进及更正留痕；原迁移兼容测试继续保留。业务写入仅使用隔离库。
