# 首页代码学习

首页是静态 Astro 页面，首屏使用现有 React Island 激活浅弧封面带。文案和素材仍由一份配置管理，不读取业务数据库。正式界面以已确认的九图持续循环样片为基准。

## 文件地图

| 文件 | 职责与修改入口 |
| --- | --- |
| `src/data/home.ts` | Meta、标题、使命、三项目标、封面、六阶段与系统入口 |
| `src/pages/index.astro` | 组装首屏、六阶段说明、三条系统入口和页脚；根路径静态生成 |
| `src/components/ContentTunnel.tsx` | 首屏 React 结构及服务端初态；通过 `client:load` 激活 |
| `src/components/ContentTunnel.module.css` | 首屏局部样式，避免影响业务页面 |
| `src/scripts/home-motion.ts` | 单相位循环、纵向展开、暂停、减少动态与事件清理 |
| `src/styles/home.css` | 首页基础变量、字体与后两区紧凑排版 |
| `public/images/home/` | 九张公开原图及素材说明 |
| `tests/home.browser.mjs` | 真实构建的桌面浏览器回归与确认样片对照 |

## 内容如何进入页面

`index.astro` 从 `homeContent` 读取内容。`hero`、`mission`、`covers` 和 `workflow.stages` 作为 Props 传给 `ContentTunnel`，后两区则直接通过 Astro 的 `.map()` 生成。

同一份六阶段数组同时驱动首屏轨道与正文说明，避免顺序或名称漂移。系统入口有 `href` 时才输出链接；建设中与授权状态保持文字，不伪造可执行入口。

文案、图片与阶段优先改配置。`CoverItem.image` 使用 `/images/home/` 下的公开路径；`label` 与 `caption` 用于图片替代文本和缺图回退。图片未设置或加载失败时仍保留封面尺寸与可辨认的文字。

## 为什么先输出静态初态

Astro 在服务器端生成 React HTML，再由浏览器加载脚本激活。`initialCoverStyle` 先输出浅弧初始位置、尺寸、旋转和透明度，使图片在脚本加载前已经正确排列。动效接管后写入同一批节点，不克隆封面，也不把图堆在原点等待初始化。

## 单相位如何保持连续

`attachHomeMotion(hero)` 只查询当前组件的 `data-home-*` 节点，并返回清理函数，供 React 卸载时执行。

横向 `phase` 表示封面带已经前进多少个位置。初始以 2.6 秒停留、1.15 秒推进一张的节奏累计；纵向 `progress` 则来自 Hero 相对视口的正常滚动距离。

`settle` 将纵向进度转换为展开程度。它插值浅弧与平带的间距、高度、尺寸、角度和渐隐，同时把横向速度逐渐过渡到每秒约 0.22 个位置。控制器混合每帧的相位增量，不混合两套绝对位置，因此滚动不会把轮播重置或反向拉回。

每张图由循环偏移计算当前位置，只在场景外回收。平带的间隔与封面宽度保留余量，两侧窄渐隐进一步隐藏回收边界。01–06 只根据纵向进度更新，自动轮播不改变流程阶段。

## 暂停与生命周期

- 暂停按钮冻结横向相位，纵向滚动仍可改变展开程度；键盘可暂停与恢复。
- `IntersectionObserver` 判断首屏是否可见，页面隐藏也暂停时钟；恢复时从当前画面继续，不补播离开期间的时间。
- `ResizeObserver` 与窗口尺寸变化更新几何，避免按旧尺寸排列。
- 减少动态效果时采用静态浅弧，CSS 取消额外滚动占位。
- 卸载时取消 RAF、observer、图片错误监听与页面事件；`pageshow` 保留浏览器返回后的恢复路径。

## 后两区如何收紧

工作流使用侧标题＋3×2 阶段说明，系统入口使用相同内容轴上的三行列表。两区按正常文档流承接深蓝首屏，不覆盖首屏，也不增加整屏高度占位。宽度和间距在 `home.css` 中维护；核心文案继续来自配置。

## 如何验证修改

先运行 `pnpm build`，再运行 `pnpm test:home`。测试只提供构建后的静态首页与公开资源，不连接业务数据库。它检查三档桌面、样片几何、九图回收、持续横移、暂停、键盘、六阶段、往返、缺图与减少动态，并录制实际操作。

生成截图仍需打开查看，尤其关注中央焦点、边缘渐隐、封面与文字净距、展开连续性以及平铺后是否持续流动。最终证据按 [verified 索引](../verified/README.md) 归档，日常浏览器配置见[测试说明](../tests/README.md)。
