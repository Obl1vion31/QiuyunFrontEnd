# 历史归档

保存用户要求保留的阶段计划、交付与日期跟进。内容反映记录当时的状态，可能包含已被替代的认证、数据环境和业务规则；现状以 [最新交接](../../handoff.md) 与 [已确认决定](../DECISIONS.md) 为准。

- [计划](plans/README.md)：批准范围或待实施提案；归档不代表已经实现。
- [结果与跟进](results/README.md)：当时的交付、验收和后续安排。
- [旧阶段总结](20260731-stage-summary.md)：原阶段现状快照。

日常协作更新最新交接；只有用户明确要求保存时才增加独立历史记录。旧文件保留正文，仅修复导航及添加归档提示。
