# 路线图

最新实现与验证见[项目交接](../handoff.md)，本页只维护当前、下一步和暂缓事项。

## 当前

- 工作分支供用户最终验收，新增核对首次推广业务日期、待定末日空下一步、当日暂停、历史缺口补录与排期待审；同时继续核对统一发布、月历、复盘入口与轮次基准，以及 2 小时登记提醒、实际发布时间结算、改期审批边界、详情单一正文滚动与待办分层、全历史两小时口径及逐账号审核权限；后续 UI 按统一基准逐项收敛，问题与接手顺序更新在最新交接。

## 下一步

- 用户确认验收后合入 `main`，再邀请其他账号试用；按实际使用反馈核对排期、推广与同类基准，不编造无法取得的历史指标。
- 年度规划中“待定”备注获得真实业务结论后补充；新年度按需从空白目标年度复制。
- [Phase 07 待实施提案](archive/plans/phase-07-monthly-review-and-moments-schedule.md)：简化 Monthly Review 与朋友圈排期；本轮数据导入不包含这些模块。
- 评估年度规划与具体帖子排期的关联方式，确认前不自动生成帖子。
- 根据真实素材和多设备反馈继续核对首页可读性、动态效果及控制台密度。

## 暂缓

- 团队一键暂停已移除，熟悉现有单帖流程后再讨论是否需要批量能力。

- 通用上传导入、导出与独立报表中心。
- 组织与人员、绩效与报酬模块。
- 跨其他业务模块的细粒度权限、完整个人审计、自动采集、自动报告及第三方同步。
- Git 自动部署或部署架构变更。
