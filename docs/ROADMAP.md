# 路线图

## Now

- 实施帖子、内容版本和排期拆分，将历史排期安全映射为独立 V0。
- 将“新增排期”升级为“新做帖 V0”，并实现从原版本派生 V1+ 的改帖工作流。
- 本地接入 Neon 开发分支并完成运营内容排期 MVP 的真实保存验收。
- 验证推广看板只包含付费测试/放量内容、完成情况自动计算、月度台账/月历、完整编辑和 12 小时延期规则。
- 验证共享凭据、数据库异常、桌面端和移动端状态。
- 验收内容发布控制台的紧凑时间轴台账、统一推广筛选、右侧 Inspector / Sheet 和移动端底部导航。
- 完成独立学科字典、共享帖子分类、学科可用分类映射，以及创建改帖说明字段简化。
- 将排期页临时 Basic Auth 扩展为多账号独立凭据，保留旧单账号配置兼容。
- 完成推广帖 Daily Promotion Review 首轮实现：排期推广身份、测试/放量生命周期、T+1 日度事实、六项输入、两项实际成本、月份语义轴和最近 90 天历史总览。
- 审核“内容穿越总控台”首页的实际观感。
- 检查八张真实封面在统一遮罩下的对比度与文字可读性。
- 检查桌面端、移动端和减少动态效果模式。

## Next

- 6 个年度规划待确认数量在获得真实业务结论后补充；该事项不重新开启 Phase 04。
- 评估年度规划与具体内容排期的关联方式；未确认前不自动生成帖子或排期。
- 评估跨年度复制，保持恢复和复制都以新版本/新规划写入，不覆盖历史。
- 使用真实推广数据验收 Daily Promotion Review 的连续补录、阶段流转、生命周期日历和移动端操作；根据验收反馈进行小范围调整。
- 评估排期删除、通用导入导出和正式多人权限，进入实施前需重新确认范围。
- 确认组织与人员、绩效与报酬两个入口的真实去向或继续保持占位状态。
- 根据真实封面色彩微调 Hero 的遮罩、对比度和深度参数。

## Later / 暂缓

- 非推广帖复盘、推广周月年汇总、独立数据填报和报表中心；
- 组织与人员模块；
- 绩效与报酬模块；
- 正式后台、登录和细粒度权限；
- 自动采集、自动报告和第三方同步；
- 生产部署。
