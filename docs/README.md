## 维护约定

- 当前说明直接描述最终有效方案；规则、设计与优先级分别进入三份核心文档，专题文件说明操作和定位，不再复制整套业务规则。
- 最新交接滚动更新，避免再维护一份内容重复的状态总结。历史计划不等于已交付，归档文件不能覆盖现行规则。
- 日常计划在会话中展示，常规实现以 Git 和交付回复留痕；只有用户明确要求长期保存时才新增日期跟进或专题记录。
- 原始表格、核对截图、备份与测试产物留在私有目录，不作为文档附件公开。
