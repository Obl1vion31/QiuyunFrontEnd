# Phase 02：运营内容排期 MVP

本阶段按 [`2MVP.md`](./2MVP.md) 实施。确认范围为新增、查看、四类筛选、月度汇总、Neon PostgreSQL、Drizzle ORM、Astro 动态页面和临时 HTTP Basic Auth；不包含编辑、删除、导入导出、正式权限、部署或自动同步。

- [x] 完成 Astro hybrid、Node adapter、数据库 schema、迁移、认证中间件、动态页面和写入接口。
- [x] 完成新增表单、四类筛选、月度汇总、响应式台账和错误状态。
- [x] 完成类型检查、构建、迁移文件一致性、401、403、422 和数据库不可用状态验证。

## 当前判断与下一步

页面显示“数据库暂时不可用”表示服务端查询失败；此时页面以空列表降级展示，所以继续筛选仍然为空，不能据此判断数据库里是否已有记录。先完成连接和迁移验证，再验证新增与筛选。

本阶段没有种子数据或自动导入任务。根据已确认范围，不编造业务数据；真实排期应由用户通过新增表单录入。若需要导入既有排期，必须另行确认数据来源、字段映射和敏感信息边界。
