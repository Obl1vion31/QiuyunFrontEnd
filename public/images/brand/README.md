# 湫云图标

用户确认的 E3 云形翻转带图标，只保留图形，不含中文字标、拼音或方案编号。

- `qiuyun-mark.svg`：透明底主文件，三个贝塞尔路径；深蓝 `#173655`、青绿 `#28968d`，不嵌入位图。
- `qiuyun-mark.png`：由同一矢量文件渲染的透明 PNG，2048×1408px。
- 根目录 `favicon.svg`、`favicon.ico` 与 `apple-touch-icon.png`：同源图形的正方形站点图标。小尺寸入口使用白色底板，保证深浅浏览器主题下可辨认；下载主文件保持透明。

修改图形应从 SVG 主文件开始，再重新渲染 PNG 和站点尺寸，不分别描摹或重新生成形状。各页面通过 `SiteIcons.astro` 使用同一组站点图标；更换时同步更新组件中的缓存版本。
