# 账号与权限

本目录负责内部用户名登录、数据库会话、账号初始化和管理员／员工权限。

- `auth.ts`：Better Auth、Drizzle adapter、可信来源与数据库共享限流；配置只在服务端读取。
- `permissions.ts`：统一请求权限、业务事务中的管理权限检查和安全登录返回地址。
- `provision.ts`：受控账号创建，密码只保存 scrypt 哈希，重复创建不修改原密码或角色。
- `client.ts`：登录、退出的浏览器请求与中文失败提示，不保存密码或会话令牌。

身份只来自已验证的数据库会话。两种角色共用团队业务数据，网页隐藏入口和服务端拒绝共同生效；角色不接受客户端修改。公开认证接口只开放用户名登录、会话读取和退出。

新增权限应同时修改请求检查、业务事务检查与隔离测试；任何会删除或重建后续事实的操作必须在确认实际影响之后、写入之前检查管理员权限。会话及角色不跨请求缓存。
